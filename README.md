# AgoraS6
Bienvenue dans le projet **AgoraBo** ! Ce projet est une application web développée avec **Symfony**, utilisant **Twig** pour le rendu des vues.

## Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés :

- **PHP** (version 8.1 ou supérieure)
- **Composer** (pour la gestion des dépendances PHP)
- **Symfony CLI** (optionnel mais recommandé pour une gestion facile du projet Symfony)
